## View formats

- Generic JSON: ordinary lexical compact JSON; optional uniform object arrays encoded as `{"columns":[original keys],"rows":[original values]}`. Header/key spellings and every nested value token retained. NDJSON preserves records/order/control footer; arbitrary line logs never deduplicated. Generic CLI JSON admitted only for known machine-output producers (node non-test scripts, python non-pytest scripts, jq, curl JSON, system_profiler -json, npm ls --json, docker/kubectl explicit JSON, gh api, powershell/pwsh ConvertTo-Json); unknown CLI producers preserve.
- CDP: native `{nodes:[AXNode...]}` or JSON-RPC `{id,result:{nodes:[...]}}`. Replace only nodes array with compact columns/rows; optional cells encode `[]` for absent, `[original value]` for present and include fixed `cellEncoding:"optional"`. All envelope fields stay. This is a model view; structuredContent remains unchanged.
- Paths: original common directory prefix followed by colon/newline and original relative suffixes, one per row; losslessly reconstruct every original absolute path. No filename/row sampling. Native glob metadata.count must equal captured path count and truncated=false. Grep retains source path + every line number and text; metadata.matches must agree. Read files retain source lines/location by default; only directories have a native compact view.
- Snapshots: existing metadata/page/event/modal sections intact, every ref/uid retained; move reference value to front and remove fixed reference syntax only, maintain hierarchy and verbatim semantic row payload. Fence becomes text when representation changes. Names with ambiguous quoting/newlines or unsupported rows preserve entire snapshot. No semantic wrapper/node pruning or newly invented counts.
- CLI: only exact recognized ps/ls/ffmpeg argv and native full grammar. Do not normalize CR redraws, remove unknown lines, or discard warning/error payloads. ffmpeg removes intermediate known progress blocks only when final block is `progress=end`, counters consistent and mandatory flags include `-hide_banner -loglevel error -nostats -progress pipe:1`.

## Independent planning review: resolved contracts

- Completeness is the received/requested tool response, not a claim that a database/page/system inventory is exhaustive. A successful fully decoded MCP response is transport-complete at the verified after-hook boundary; absence of isError alone is insufficient without that carrier/lifecycle. Generic JSON transforms retain the ENTIRE received data, including pagination/scope fields. Explicit producer truncation flags or error envelopes refuse transformation. Snapshots with target/depth/file output args are left unchanged; unknown clipping notices/ellipsis/literal multiline grammar refuse. Native wrappers with truncated=true or unknown completeness refuse.
- MCP mapping: validate content array and each block shape before reducing; process each text block independently, never concatenate partial fragments into a pretend JSON/snapshot. Candidate content is a new array, copying ONLY changed text blocks, retaining annotations and all untouched blocks' identity. structuredContent/resource/image/audio/data stay untouched. Commit content atomically after budget, raw-save and unchanged-original checks. Cap total text + resource.text at maxInputBytes and blocks at 64; binary-resource blob notices cannot be predicted safely, so automatic transformation of packets containing resource.blob refuses. Optional raw captures exact host-joined text/resource.text, not serialized image data. Standard isError true, malformed flags/content, metadata.truncated=true and text error/clipping envelopes preserve WHOLE packet.
- Directory read requires effective offset 1 (omitted/0/1) and exact footer count equal to parsed entries. If metadata.display exists, type/path/offset/count/entries/truncated must agree. Native file reads keep lines and source locations unchanged. Glob requires genuine metadata.count and exact path count; grep genuine metadata.matches and exact header/match count. Error/truncation footers refuse. A lossless path-prefix view must reconstruct every original pathname, not merely list basenames.
- Generic MCP JSON does not require a recognized tool name: the recognized format is COMPLETE JSON in a verified native CallToolResult text block, with full key/value retention. Unknown plaintext carriers remain untouched. Native text snapshot semantic formatting additionally requires `_browser_snapshot`/`browser_snapshot` or `_take_snapshot`/`take_snapshot`, exact known section prefix/fence/row grammar, no partial args and full ref/hierarchy preservation.
- CLI argv frozen: ps direct `-axo pid,ppid,stat,comm` or `-eo pid,ppid,stat,comm`; ls direct `-l`, `-la`, `-al`, optional `--`, zero/one path, ordinary file/directory/symlink rows only; ffmpeg mandatory flags above unique/nonconflicting. Generic JSON producer checks: node excludes --test, python excludes -m pytest, system_profiler requires -json, npm requires ls/list plus --json, docker requires --format json or exact `{{json .}}`, kubectl requires -o/--output json, gh requires api, powershell/pwsh requires ConvertTo-Json. jq/curl complete JSON syntax is mandatory. All commands literal-tokenized; pipelines/metacharacters and matched legacy refusals remain original. B may conservatively refuse an unobserved layout rather than expand grammar.
- Precedence: legacy native bash result first; then CLI/file/snapshot/CDP specialized reducers; generic JSON last. Failed reductions never cause a weaker semantic reducer to omit unknown data. Lexical fallback retains all received fields; no field sampling/removal. Unknown native IDs only generic MCP carrier language admission applies, not builtin success inference.
- Evidence obligations: JSON minification declares every key/scalar/empty-container punctuation; uniform table declares original column keys once and EVERY nested value token in every row; CDP declares all envelope data and every node field/value/ref including extensions and empty values; paths declares prefix and every suffix with independent full-path reconstruction; grep paths/line numbers/text all retained; snapshots every ref and complete semantic row payload plus untouched metadata/event/modal sections. All record/hierarchy order retained. Mutation removes both emission AND corresponding required declarations to prove semantic oracle, not only renderer, catches loss.

### Frozen snapshot/error vocabulary

Playwright snapshot tool name is exactly `browser_snapshot` or ends `_browser_snapshot`. Accepted args: empty object or only `boxes:boolean`; presence of target/depth/filename or any unknown arg refuses semantic snapshot reformat. Exactly one `### Snapshot\n\x60\x60\x60yaml\n` block; opening/closing fences complete and no nested/literal block. All preamble/suffix bytes preserved. Body rows have even-space indentation and `- `, followed by a lower-case ARIA role token or property `/url:`, `/placeholder:`, `/description:`. Unknown roles may be retained verbatim, not omitted; each ref-bearing row must have exactly one bracket attribute `[ref=eDIGITS]` or `[ref=fDIGITSeDIGITS]` BEFORE any unquoted value colon. Double-quoted names/strings use balanced escaped quote scanning; brackets within quotes are data, never refs. Other bracket attributes (states/level/box/etc) and value text are opaque verbatim source spans. Non-ref rows stay verbatim. Reject unclosed quotes/brackets, odd indentation, duplicate refs, ellipsis rows, literal `|`/`>` continuation and unsupported line production. Reformat by moving ONLY ref value to front and deleting `- `/fixed `[ref=...]` syntax; all remaining payload and indentation retained. Fence info changes from yaml to fixed text. At least two valid refs and a strictly smaller whole response required.

Chrome DevTools name is `take_snapshot` or ends `_take_snapshot`; args empty or only `verbose:boolean`, never filePath/unknown args. Exact `## Latest page snapshot\n` followed only by even-indented uid rows and optional terminal LF. Every row begins `uid=DIGITS_DIGITS `, refs unique, payload nonempty and quotes single-line/balanced; preserve every role/name/attribute/panel-selected suffix as opaque source span. Remove only fixed `uid=`; same indentation/ref value/payload remain. Unsupported notes/extra sections/multiline names refuse. No renderer-derived counts or node deletion. Real capture validates these finite admitted productions before enabling defaults; if producer differs, lead revises frozen contract explicitly.

Packet refusal vocab: raw `isError:true`; raw isError present nonboolean; raw metadata.truncated present and not false; raw metadata.exit present and not safe integer zero; malformed content/block fields; any resource.blob; text containing top-level outside-fence `### Error` (Playwright error section); exact host clipping wrappers beginning `...output truncated...` or matching the native leading `...N lines/bytes truncated...` marker. JSON error packets recognized only as standard JSON-RPC (`jsonrpc:"2.0", error:{code:number,message:string}`) or CDP (`id:number,error:{code:number,message:string}`, no result); these stay byte-exact. Do NOT infer failure/truncation from arbitrary application JSON keys named error/status/truncated/hasMore. Generic JSON is lossless representation of the full received payload, including pagination/scope flags, not a claim of exhaustive producer data. Marker checks are protocol-positioned, not prose searches inside quoted UI/file data.

## Contract revisions after review (lead, 2026-10-10)

Explicit revisions to the frozen text above, each driven by real captures or cold review:

- Chrome DevTools `take_snapshot` also admits a positive safe-integer `pageId`: the real default producer (DevTools MCP 1.10.1 without `--no-page-id-routing`) sends `{pageId:1}`. `filePath` and unknown args still refuse.
- Generic JSON is lexical only (whitespace outside tokens). The optional uniform-array `columns/rows` encoding is implemented for native CDP AX nodes only, not for arbitrary JSON.
- Bash `node` JSON producers are user scripts only: arguments with `--test` or any `node_modules` path segment refuse, so package CLIs such as Playwright/Vitest JSON reporters keep their exact-ledger families.
- Native routing is limited to `glob`, `grep` and `read`. `list_mcp_resources`/`list_mcp_resource_templates` had no reducer and are no longer routed.
- Refusal classes added by review: grep path suffixes that are empty, start with whitespace, a format character or a combining mark, or contain any line break; Playwright snapshot hierarchy (depth steps of one, children only under element rows ending in a bare `:`, no childless containers, `text`/property rows never parents, no valueless `text` rows, no space before the value colon); Chrome snapshots with exactly one leading depth-0 `RootWebArea`; CLI numbers bounded lexically before conversion (ffmpeg int64 fields and clock hours, `ls` nlink/total uint64 and size int64, `ps` PID/PPID by kernel limit: Darwin 99999, Linux 4194303).
- Core and adapters read caller-owned objects once: reduction pieces/required/text, reducer entries, hook tool/args/metadata, MCP content blocks. The exported core refuses contradictory `truncated`/`exit` metadata for every source. MCP aggregate budget is checked before any parsing, and after an awaited raw save the whole live packet (array, slots, text, flags, tool, args) is revalidated before one atomic assignment.
