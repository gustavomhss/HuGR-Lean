# Profile manual

`profiles`, `runnerProfiles`, and `formatProfiles` are internal readonly arrays, not package subpath exports. Consumers use `filter` from `hugr-lean/core`.
Each entry implements `match(argv): boolean` and `reduce(output, observation): Reduction | undefined`; core resolves identity and validates/renders the result.

Launchers are per-row, never inferred from npm scripts or rewritten Node commands. Explicit Jest/Vitest reporter flags decline; config-only reporters cannot be authenticated from argv/grammar, so whole-row retention protects admitted shapes. Core-owned safe presentation normalization remains distinct from plaintext reduction.
All reductions require complete shell exit 0. Controls, unknown rows, inconsistent summaries and unsupported layouts refuse; supported warnings/logs survive. [Core](../core/MANUAL.md) owns conditional SGR handling. T01/pnpm/ESLint/Biome/Go JSON/Pyright/Pylint require unknown presentation; layout bounds differ, so LF/CRLF support is not universal.
Closed limits include Cargo-test <=64 argv, <=8 packages/excludes/skips, <=16 features/1024 characters, <=128-character target; Go text count <=100, parallel <=256, name depth <=128; T01 <=128 unique projects, final root binding and exact EOF. pnpm <=1,048,576 UTF-16 units/10,000 rows, counters <=1,000,000 and package count <=10,000. These local caps supplement core UTF-8 input limits; source spans remain UTF-16.
Ruff/Pyright/Pylint share [json-layout.ts](json-layout.ts): parse/schema first, compact only outside-string whitespace, require canonical token round-trip. Duplicate keys/alternate escapes/noncanonical numbers refuse; no JSON reserialization. Pyright requires exactly native two-LF ending; Pylint requires LF-ending full terminal whitespace. Optional Pylint flags: --persistent=no, --jobs=1, --exit-zero, --reports=yes, --rcfile=PATH, each once. Actual exit 0 is always required, even without --exit-zero.
Automatic reducers (`auto-cli`, `auto-files`, `auto-snapshot`, `auto-cdp`, `auto-json`) take one frozen `AutomaticObservation` and return a source-backed `Reduction` or `undefined`; [automatic.ts](../core/automatic.ts) runs them in that order after the legacy registry. `auto-cli`: exact `ps -axo|-eo pid,ppid,stat,comm`, `ls -l|-la|-al [--] [path]`, ffmpeg with mandatory progress flags; cells become tab-separated, ffmpeg keeps only the final `progress=end` block; numeric cells stay within kernel/int64/uint64 bounds or refuse. `auto-files`: glob/grep common-prefix factoring with counts equal to metadata; grep suffix ambiguity refuses; directory read drops only `<entries>` tags. `auto-snapshot`: ref-leading Playwright/DevTools rows under the frozen hierarchy/container grammar. `auto-cdp`: nodes as optional-cell columns/rows within 25,000 cells, consistent field order and no key aliases. `auto-json`: whitespace-only compaction within 25,000 nodes/records. Full table: [coverage](../../docs/COVERAGE.md#automatic-native-views).
Git requires a native footer for ordinary unstaged/untracked-only output; complete staged or explicit merge variants may end after entries. Quoting/escapes/localization/porcelain/rebase advice decline.
Ripgrep numeric-only/colon-bearing/Windows-drive paths, columns, context/headings, or ambiguous numeric content delimiters decline; ordinary content colons remain valid.
Version pins are capture bounds, not authenticated runtime binaries; identical text from another producer can be indistinguishable. Exact argv/source/provenance and named tests live in the per-family CASES/SOURCES links in [coverage](../../docs/COVERAGE.md); Cargo-test/Go JSON/T01 pins live in CASES. Legacy [runners](../../fixtures/runners/SOURCES.md)/[formats](../../fixtures/formats/SOURCES.md) and utility evidence are reused. Exact-ledger families have no new parsers or support promise.
