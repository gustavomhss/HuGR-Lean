## Recipe

Run `python3 fixtures/profiles/jest/capture.py` in a fresh packet destination. Script creates
private scratch tool/project dirs under approved temp root, installs only pinned local Jest
with `--ignore-scripts --no-audit --no-fund`, then invokes `jest` via isolated PATH.
Native tests are tiny; no global install or package dependency change.
Exact per-case argv, cwd, environment, known exits and sequencing are in receipt/manifest.
Snapshot-written cases seed `.snap` files; passing cases reuse them; `R02_FAIL=1` changes received
count without modifying source. Reporter module is authored collision witness.

Boundary: stdout pipe, stderr merged before exec; read through EOF and wait. No PTY,
line rewrite, decoding normalization, trimming or output reconstruction. UTF-8 round-trip,
EOF tail hex, final LF, SHA-256 and byte counts are retained for every input.
`finalize.py` archives actual version and verifies immutable coverage-asset provenance.
`classify.mjs` records only existing baseline behavior with independent golden; loader command:

```
node --import /Users/gustavoschneiter/Documents/HuGR/HuGR-Lean/node_modules/tsx/dist/loader.mjs fixtures/profiles/jest/classify.mjs
```

Reproduction timings/source absolute paths may vary; original captures remain authoritative.
`archives` is a flat string-path list of every packet file except manifest and native inputs,
including licenses, candidates, scripts, snapshots, reports, receipt and golden.
`archive.py` reconciles flat archives and hashes without native/filter replay.
Fixture-local `.gitattributes` disables text conversion, preserving attachments on checkout.
