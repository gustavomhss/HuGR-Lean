Usage: bun test [flags] [<patterns>]
  Run all matching test files and print the results to stdout

Flags:
      --no-orphans                    Exit when the parent process dies, and on exit SIGKILL every descendant. Linux/macOS only.
      --timeout=<val>                 Set the per-test timeout in milliseconds, default is 5000.
  -u, --update-snapshots              Update snapshot files
      --rerun-each=<val>              Re-run each test file <NUMBER> times, helps catch certain bugs
      --retry=<val>                   Default retry count for all tests, overridden by per-test { retry: N }
      --todo                          Include tests that are marked with "test.todo()"
      --only                          Run only tests that are marked with "test.only()" or "describe.only()"
      --pass-with-no-tests            Exit with code 0 when no tests are found
      --concurrent                    Treat all tests as `test.concurrent()` tests
      --randomize                     Run tests in random order
      --seed=<val>                    Set the random seed for test randomization
      --coverage                      Generate a coverage profile
      --coverage-reporter=<val>       Report coverage in 'text' and/or 'lcov'. Defaults to 'text'.
      --coverage-dir=<val>            Directory for coverage files. Defaults to 'coverage'.
      --bail=<val>                    Exit the test suite after <NUMBER> failures. If you do not specify a number, it defaults to 1.
  -t, --test-name-pattern=<val>       Run only tests with a name that matches the given regex.
      --reporter=<val>                Test output reporter format. Available: 'junit' (requires --reporter-outfile), 'dots'. Default: console output.
      --reporter-outfile=<val>        Output file path for the reporter format (required with --reporter).
      --dots                          Enable dots reporter. Shorthand for --reporter=dots.
      --only-failures                 Only display test failures, hiding passing tests.
      --max-concurrency=<val>         Maximum number of concurrent tests to execute at once. Default is 20.
      --path-ignore-patterns=<val>    Glob patterns for test file paths to ignore.
      --changed=<val>                 Only run test files affected by changed files according to git. Optionally pass a commit or branch to compare against.
      --isolate                       Run each test file in a fresh global object. Leaked handles from one file cannot affect another.
      --parallel=<val>                Run test files in parallel using N worker processes. Implies --isolate. Defaults to CPU core count.
      --parallel-delay=<val>          Milliseconds the first --parallel worker must be busy before spawning the rest. 0 spawns all immediately. Default 5.
      --test-worker                   (internal) Run as a --parallel worker, receiving files over IPC.
      --shard=<val>                   Run a subset of test files, e.g. '--shard=1/3' runs the first of three shards. Useful for splitting tests across multiple CI jobs.

Examples:
  Run all test files
  bun test

  Run all test files with "foo" or "bar" in the file name
  bun test foo bar

  Run all test files, only including tests whose names includes "baz"
  bun test --test-name-pattern baz

Full documentation is available at https://bun.com/docs/cli/test
