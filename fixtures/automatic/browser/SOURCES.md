## Serialization and preservation

`*.stdin.bin`, `*.stdout.bin`, `*.stderr.bin` are exact stream bytes captured from subprocesses. `playwright.json` and `devtools.json` serialize complete decoded JSON-RPC requests/responses, including initialize, tool schemas, all native MCP fields, errors and arguments. They are not wire-byte claims. `cdp-before.json`/`cdp-modal.json` serialize actual decoded CDP results returned through native Playwright code execution: full `Accessibility.getFullAXTree`, `Browser.getVersion`, `Target.getTargetInfo`, `Browser.getWindowForTarget`. Source AX rows are never normalized, sampled or filtered. Producer-created YAML/log artifacts remain original. Receipt hashes every generated artifact and preserves all stderr, argv and failures. UTF-8 byte metrics; no span normalization.

Initial failed attempts remain private at `/var/folders/lt/z11pyzhj0m17vn798jkk69hh0000gn/T/opencode/wp-f-native` (unadvertised `browser_run_code`), `wp-f-native-cdp` (working CDP, no DevTools entry), and `wp-f-native-both` (default DevTools pageId validation errors). They are not relabeled successful captures.

Later latest-harness run `wp-f-native-final` captured working Playwright/CDP but DevTools initialization exceeded the bounded default 30 seconds (`Error: Timeout: initialize`); full stderr/partial streams/argv/receipt remain there. Committed `native/` is the earlier successful two-producer capture, not that timeout run.

Manual reproduction: `node scripts/automatic-browser-capture.mjs --output PRIVATE_TEMP --playwright /absolute/playwright/cli.js --executable /absolute/chrome-headless-shell --devtools /absolute/source/build/src/bin/chrome-devtools-mcp.js`. Output must be a fresh private directory. Native execution is manual; portable tests replay committed responses and run original protocol controls, requiring no GUI/browser installation. No CI configuration changes.

## Native grammar findings

- `browser_snapshot {}` returns `### Page` then `### Snapshot` fenced `yaml`, even indent, `[ref=eN]`, escaped double quotes, non-ref `- text:`/`- option` rows, `/url:` rows, states. Modal response adds `dialog` and `[active]` textbox; no separate modal section for HTML dialog.
- Navigation/click responses return `### Snapshot` with Markdown file links rather than inline YAML. Preserve these unsupported semantic carriers; do not pretend the linked contents were inline.
- Installed Playwright tool is `browser_run_code_unsafe`, not `browser_run_code`; DOM evaluation wraps pretty JSON in `### Result` followed by `### Ran Playwright code`, not bare JSON. `browser_console_messages` schema requires `level`; `browser_network_requests` requires `static`. CallToolResult success omits `isError`; deliberate evaluate failure has `isError:true` and `### Error`.
- DevTools defaults require `pageId` on `take_snapshot`, contrary to frozen empty/verbose-only args. Captured successful empty-args mode uses explicit `--no-page-id-routing`; default validation failures preserved separately. Output starts exactly `## Latest page snapshot\n`; even-indented `uid=N_N ` rows and terminal LF match the planned envelope. Inner quotes are **not escaped**: `uid=1_3 textbox "Name "東京"" value="Zoë"`. Text-only rows have no role: `uid=1_2 "Name "東京""`. Attributes include bare `disableable disabled`, `checked`, `expandable haspopup="menu"`, `focusable focused`, `modal`. UIDs need not be contiguous. Native modal snapshot contains only RootWebArea and dialog subtree; producer omission is not harness sampling. Evaluate result instead uses `Script ran on page and returned:\n` plus a `json` fence. Default `pageId` and ambiguous inner quoting require explicit lead contract decisions before enabling semantic reformat.
